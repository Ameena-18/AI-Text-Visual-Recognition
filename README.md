# AI-Based Text and Visual Recognition System

## Project Overview
This project combines three AI applications: text sentiment classification, object detection, and facial landmark detection.

## Modules

### 1. Text Classification
- Uses TensorFlow and Keras.
- Classifies movie reviews as positive or negative.
- Uses the IMDB dataset.

### 2. Object Detection
- Uses a pre-trained SSD MobileNet model.
- Identifies objects in uploaded images.
- Displays bounding boxes and predicted labels.

### 3. Facial Landmark Detection
- Uses MediaPipe and OpenCV.
- Detects facial landmarks.
- Visualizes facial points on uploaded images.
